Context

See proposal.md. The existing codec omits empty cells, and both construction and parsing trim empty boundary lines. Existing tests require those normalized defaults.

Goals and non-goals

Retain source-cell structure through a public opt-in path on all four targets. No output persistence, alternate metadata schema or byte-exact line-ending preservation is added.

Decisions

DIB-1. Explicit source mode (Call)

Add SourceMode with Normalized and Lossless cases. Use the same optional mode in Cell construction, parse and to_string. Normalized remains the default. Changing the default would break documented .NET Interactive normalization. An opt-in mode supplies the supported lossless path requested in issue #109.

DIB-2. Selector framing without payload padding (Call)

Lossless writing emits each canonical selector, one LF, its exact LF-normalized source and one framing LF. Blocks concatenate without an extra separator. Lossless parsing retains explicit empty selectors and all payload lines, excluding only the terminal split sentinel. A zero-cell notebook writes empty text and reads as zero cells in this mode. No extension directive or hidden metadata is needed.

DIB-3. Existing representation refusal (Call)

Both modes reject source containing registered selectors with the existing cell/line error. Keep metadata output, leading BOM support and custom registry handling. A first metadata header protects later metadata directives retained as source. Reuse the current registry on reread.

Risks and trade-offs

RiskMitigation
A caller mixes source modes.Document that lossless export/import uses Lossless at every relevant boundary. Show a runnable example with one shared mode value.
Framing is mistaken for source.Test empty, newline-only, trailing-newline and consecutive cells, with and without metadata.
Default output changes.Retain all existing default-mode fixtures and assertions.

Migration plan

The API is additive. Existing consumers keep Normalized. Morphir opts into Lossless for construction, export and import. Land with the task evidence and the requirements, then publish in the authorized shared release. Rollback is to the previous version or Normalized mode.
