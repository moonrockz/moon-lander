Moon-Lander

An application framework for MoonBit. Build an application one time and land it on a host: the web, WebAssembly or a native process.

Read the Design overview. It explains the proposed hosting and configuration design, in the order that one run uses it.

Install the framework with moon add moonrockz/moon-lander@0.6.0, or choose the core, logging, config, mediator, logging-hosting-async and hosting modules separately. All seven framework modules, notebooks and OpenRPC are available from mooncakes.io at the same release version.
